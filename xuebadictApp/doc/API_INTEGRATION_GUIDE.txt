API 端点说明
================================================================================

1. 获取最新应用版本
────────────────────────────────────────────────────────────────────────────
请求:
  GET http://app.mty.mingboai.com/api/version/app/latest?platform=android

响应 (成功):
  {
    "success": true,
    "data": {
      "version": "1.2.0",
      "build_number": 12,
      "release_date": "2026-02-04",
      "download_url": "http://app.mty.mingboai.com/download/v1.2.0/app.apk",
      "changelog": [
        "新增单词拼读功能",
        "优化语音评测准确度",
        "修复已知问题",
        "提升应用性能"
      ],
      "force_update": false,
      "file_size": "25.6 MB",
      "md5": "abc123def456",
      "platform": "android"
    }
  }

字段说明:
  - version: 应用版本号 (x.y.z 格式)
  - build_number: 构建号 (用于快速比较)
  - release_date: 发布日期 (ISO 8601 格式)
  - download_url: 应用下载链接 (包含版本号)
  - changelog: 更新内容列表 (Dart 端会转换为 Markdown)
  - force_update: 是否强制更新
  - file_size: 文件大小 (用于显示)
  - md5: MD5 校验值 (用于验证文件完整性)
  - platform: 平台 (android/ios)


2. 检查应用更新
────────────────────────────────────────────────────────────────────────────
请求:
  POST http://app.mty.mingboai.com/api/version/app/check
  Content-Type: application/json
  
  {
    "current_version": "1.0.0",
    "build_number": 10,
    "platform": "android"
  }

响应 (有更新):
  {
    "success": true,
    "data": {
      "has_update": true,
      "current_version": "1.0.0",
      "current_build": 10,
      "latest_version": "1.2.0",
      "latest_build": 12,
      "force_update": false,
      "update_info": {
        "version": "1.2.0",
        "build_number": 12,
        ...
      }
    }
  }


3. 检查兼容性
────────────────────────────────────────────────────────────────────────────
请求:
  POST http://app.mty.mingboai.com/api/version/compatibility
  Content-Type: application/json
  
  {
    "app_version": "1.2.0"
  }

响应 (兼容):
  {
    "success": true,
    "data": {
      "compatible": true,
      "app_version": "1.2.0",
      "api_version": "2.0.0",
      "min_app_version": "1.0.0",
      "message": "版本兼容"
    }
  }

================================================================================
Dart 端集成流程
================================================================================

1. 版本信息解析
────────────────────────────────────────────────────────────────────────────
API 响应 JSON → VersionInfo.fromApiJson() → VersionInfo 对象

处理步骤:
  ✓ 提取 version 字段作为版本号
  ✓ 提取 download_url 字段作为下载地址
  ✓ 将 changelog 列表转换为 Markdown 格式
    [
      "新增单词拼读功能",
      "优化语音评测准确度",
      ...
    ]
    ↓
    • 新增单词拼读功能
    • 优化语音评测准确度
    ...
  ✓ 解析 release_date 为 DateTime 对象


2. 版本比较
────────────────────────────────────────────────────────────────────────────
算法: 按点分版本号比较

示例:
  当前版本: 1.0.0
  最新版本: 1.2.0
  
  比较步骤:
    1. 比较主版本: 1 == 1 (相等，继续)
    2. 比较次版本: 0 < 2 (更新版本更新，返回 true - 需要更新)

结果: 需要更新 ✓


3. 更新流程
────────────────────────────────────────────────────────────────────────────
用户操作流程:

  设置页面
    ↓
  点击"检查更新"按钮
    ↓
  AutoUpdateService.checkManually()
    ↓
  SettingsHelper.checkForUpdates(currentVersion)
    ├─ 调用 API: GET /version/app/latest?platform=android
    ├─ 解析响应: VersionInfo.fromApiJson()
    └─ 版本比较: _isNewerVersion()
    ↓
  如果 hasUpdate == true
    ├─ 获取 VersionInfo (包含下载链接)
    ├─ 显示更新对话框 (_UpdateDialog)
    │  ├─ 显示版本号: "当前版本: 1.0.0 → 最新版本: 1.2.0"
    │  ├─ 显示更新内容 (使用 MarkdownBody 渲染)
    │  ├─ 显示文件大小: "25.6 MB"
    │  └─ 提供按钮:
    │     ├─ "立即更新" → 下载
    │     └─ "稍后更新" → 关闭
    │
    └─ 用户选择"立即更新"
       ├─ UpdateManager.downloadAndInstall()
       ├─ 显示下载进度
       ├─ 下载完成后显示"更新包已准备就绪"
       └─ 用户点击"安装"或系统自动安装

  否则 (hasUpdate == false 且手动检查)
    └─ 显示"已是最新版本"对话框

错误处理
================================================================================

1. API 服务器不可用
────────────────────────────────────────────────────────────────────────────
优先级: 自定义 API → GitHub API

如果自定义 API 服务器失败:
  ✓ 记录错误日志
  ✓ 自动回退到 GitHub API
  ✓ 继续检查更新

如果 GitHub API 也失败:
  ✓ 返回错误信息
  ✓ 手动检查时显示错误对话框
  ✓ 自动检查时静默失败 (不显示任何提示)


2. 网络超时
────────────────────────────────────────────────────────────────────────────
超时时间: 10 秒
处理: 捕获异常，返回错误结果


3. 版本号格式错误
────────────────────────────────────────────────────────────────────────────
验证: version 字段必须是 "x.y.z" 格式
处理: 使用默认值 "1.0.0"

================================================================================
常见问题
================================================================================

Q1: 更新检查多久执行一次?
A: 
  - 自动检查: 24 小时间隔 (减少服务器压力)
  - 手动检查: 用户主动点击"检查更新"按钮
  - 应用启动: 第一次启动或上次检查超过 24 小时


Q2: 如何强制更新?
A: 
  设置 "force_update": true
  客户端收到此标志后，会隐藏"稍后更新"按钮
  用户必须更新才能继续使用应用


Q3: 如何验证下载的 APK 文件?
A:
  API 响应包含 "md5" 字段
  下载完成后计算 MD5 值与响应中的值比较
  如果不一致，说明文件损坏或被篡改


Q4: 支持灰度发布吗?
A:
  暂不支持，可通过修改 version.py 实现:
  - 添加 "allow_versions" 字段
  - 记录用户版本，仅向符合条件的用户推送更新


Q5: 支持多个版本同时维护吗?
A:
  支持，可创建多个版本记录:
  - is_latest: true 标记为最新版本
  - query().filter_by(is_latest=True).first() 获取最新版本
  - 旧版本记录保留用于历史查询
