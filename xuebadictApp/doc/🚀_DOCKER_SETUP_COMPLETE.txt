🚀 启动命令速查
═══════════════════════════════════════════════════════════════════════════

  启动服务:
    docker-compose up -d

  查看状态:
    docker-compose ps

  查看日志:
    docker-compose logs -f api

  进入容器:
    docker-compose exec api bash

  停止服务:
    docker-compose down

  完全清理:
    docker-compose down -v

  重启服务:
    docker-compose restart

🆘 快速问题解决
═══════════════════════════════════════════════════════════════════════════

  Q: 容器无法启动?
  A: docker-compose logs api  # 查看错误日志
     docker-compose build --no-cache api  # 重新构建

  Q: 数据库连接失败?
  A: docker-compose logs mysql  # 查看MySQL日志
     docker-compose restart mysql  # 重启MySQL

  Q: 端口被占用?
  A: 编辑 docker-compose.yml
     修改 "5000:5000" 为 "5001:5000"

  Q: 需要重置数据?
  A: docker-compose down -v  # 删除所有数据并停止

  Q: 更多帮助?
  A: 查看 DOCKER_GUIDE.md 的"故障排除"章节
