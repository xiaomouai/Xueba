📋 核心功能
════════════════════════════════════════════════════════════════════════════

单元 → 句子 → 语音朗读
│
├─ 单元标题: "Unit 1 Hello!"
│
├─ 句子列表:
│  1. "Hello! Hello! Hello!" → "你好！你好！你好！"
│  2. "I'm Sarah. I'm Sarah." → "我是萨拉。我是萨拉。"
│  3. "Hello, Sarah!" → "你好，萨拉！"
│  ... (共 10+ 句)
│
└─ 学习流程:
   1. 播放英文句子 (TTS)
   2. 显示中文翻译
   3. 用户跟读（语音评测）
   4. 标记完成，进入下一句


🎯 使用示例
════════════════════════════════════════════════════════════════════════════

1️⃣  在首页点击"课文学习"按钮

2️⃣  打开课文学习页面:

    LessonStudyPage(
      unitTitle: "Unit 1 Hello!",
      sentences: [
        SentenceContent(
          english: "Hello! I'm Sarah.",
          chinese: "你好！我是萨拉。",
        ),
        // ... 更多句子
      ],
    )

3️⃣  用户交互:
    • 点击 [▶ 播放] 听英文
    • 查看 中文意思
    • 点击 🎤 开始录音 (语音评测)
    • 点击 [下一句] 继续学习

💾 数据模型
════════════════════════════════════════════════════════════════════════════

SentenceContent {
  english: String        // "Hello! I'm Sarah."
  chinese: String        // "你好！我是萨拉。"
  audioUrl: String?      // 音频 URL（可选）
}

LessonUnit {
  id: Int                // 1
  title: String          // "Unit 1 Hello!"

}

UserLessonProgress {
  unitId: Int
  completedSentences: List<Int>
  pronunciationScores: Map<Int, Int>
  progressPercentage(): Double  // 0.0-1.0
}

🚀 快速集成步骤
════════════════════════════════════════════════════════════════════════════

1. 导入页面:
   import 'lesson_study_page.dart';

2. 在首页添加按钮:
   _buildFunctionCard('课文学习', '...', ...() {
     _navigateToLessonStudy();
   })

3. 添加导航方法 (已在 home_page.dart 中实现):
   void _navigateToLessonStudy() {
     Navigator.push(
       context,
       MaterialPageRoute(
         builder: (context) => LessonStudyPage(...),
       ),
     );
   }

4. 导入服务（获取真实数据）:
   import 'services/lesson_content_service.dart';
   final service = LessonContentService();
   final sentences = await service.getLessonSentences(unitId: 1);
