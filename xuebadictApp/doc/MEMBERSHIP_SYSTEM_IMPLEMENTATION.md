## 实现功能

### 后端实现 (xuebaApi/)

#### 1. 用户注册自动激活试用期
**文件**: `api/auth.py`

- 新用户注册自动获得3天免费试用期
- 返回试用期结束时间
- 注册响应包含试用礼包信息

```python
# 自动激活3天试用期
trial_end_date = datetime.now() + timedelta(days=3)
```

#### 2. 会员状态API
**文件**: `api/membership.py` (新创建)

提供以下接口：

1. **GET /api/v1/membership/status** - 获取用户会员状态
   - 返回试用期信息
   - 是否已过期
   - 是否已付费
   - 是否应显示付费弹窗

2. **GET /api/v1/membership/plans** - 获取会员套餐列表
   - 基础会员（99元/年）
   - AI智能会员（299元/年）
   - VIP尊享会员（599元/年）
   - 每个套餐包含详细功能列表

3. **POST /api/v1/membership/activate** - 激活码激活会员

4. **POST /api/v1/membership/check-feature** - 检查功能访问权限

#### 3. 数据库模型
**文件**: `models/payment.py`

- `VIPMembership` - 会员信息表
- `PaymentOrder` - 支付订单表
- `UserCoins` - 用户金币表

### 前端实现 (xuebaAPP/)

#### 1. 会员服务管理类
**文件**: `lib/services/membership_service.dart` (新创建)

核心功能：
- 获取会员状态（带5分钟缓存）
- 获取会员套餐列表
- 激活会员（激活码）
- 检查功能访问权限
- 判断是否应显示付费弹窗

主要类：
- `MembershipService` - 会员服务单例
- `MembershipStatus` - 会员状态模型
- `MembershipPlan` - 会员套餐模型
- `MembershipInfo` - 会员详细信息

#### 2. 主页会员检查
**文件**: `lib/pages/home_page.dart`

功能：
- 页面加载时自动检查会员状态
- 如果试用期已过期且未付费，弹出付费对话框
- 对话框不可通过外部点击或返回键关闭（试用期过期时）
- 提供"立即开通会员"按钮跳转到会员页面

关键方法：
```dart
_checkMembershipStatus()  // 检查会员状态
_showPaymentRequiredDialog()  // 显示付费弹窗
```

#### 3. 会员购买页面
**文件**: `lib/pages/membership_page.dart`

界面设计：
- **顶部横幅** - 醒目的会员宣传
- **套餐卡片** - 三种会员套餐可选择
  - 基础会员（99元/年）- 绿色主题
  - AI智能会员（299元/年）- 紫色主题，标记"最热门"
  - VIP尊享会员（599元/年）- 橙色主题
- **立即购买按钮** - 显示选中套餐和价格
- **激活码兑换区** - 支持激活码兑换
- **购买须知** - 详细说明

特色功能：
- 卡片式套餐展示，选中有明显视觉反馈
- 显示原价和折扣价对比
- 每个套餐的功能列表一目了然
- 支持激活码兑换（适合线下渠道）

#### 4. BackendApiService扩展

新增方法：
