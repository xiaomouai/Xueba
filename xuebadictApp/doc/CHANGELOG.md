## 发布说明

### 如何升级

#### 后端升级

```bash
# 拉取最新代码
git pull origin main

# 备份数据库
cp lioneng.db lioneng.db.backup

# 更新依赖
pip install -r requirements.txt

# 重启服务
sudo systemctl restart lioneng-api
```

#### 前端升级

```bash
# 拉取最新代码
git pull origin main

# 清理缓存
flutter clean

# 获取依赖
flutter pub get

# 重新打包
flutter build apk --release
```

### 兼容性说明

- **v2.0.0** 与 **v1.x** 不完全兼容
- 需要迁移本地数据到云端
- 建议用户重新登录

### 数据迁移

v1.x 到 v2.0.0 的数据迁移：

```bash
# 运行迁移脚本
python migrate_v1_to_v2.py
```
