## 数据流

### 1. 前端发起请求

```dart
// Flutter调用
final response = await AIService.chat(
  message: '你好',
  systemPrompt: '你是Luna老师',
);
```

### 2. HTTP请求

```json
POST http://localhost:5000/api/v1/ai/chat
Content-Type: application/json

{
  "message": "你好",
  "system_prompt": "你是Luna老师",
  "temperature": 0.7,
  "max_tokens": 2000
}
```

### 3. 后端处理流程

```
接收请求
   ↓
验证参数（message非空）
   ↓
构建消息列表
   ↓
调用call_ai_with_fallback()
   ↓
┌─────────────────────────┐
│ 优先尝试千问             │
│ call_qwen_api()         │
│  ├─ 重试1次             │
│  ├─ 重试2次             │
│  └─ 成功 ✅ → 返回结果  │
└─────────────────────────┘
   │ 失败 ❌
   ↓
┌─────────────────────────┐
│ 尝试DeepSeek            │
│ call_deepseek_api()     │
│  ├─ 重试1次             │
│  ├─ 重试2次             │
│  └─ 成功 ✅ → 返回结果  │
└─────────────────────────┘
   │ 失败 ❌
   ↓
返回错误信息
```

### 4. 响应返回

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "content": "你好！有什么可以帮你的？",
    "provider": "qwen",
    "model": "qwen-plus"
  }
}
```

### 5. 前端展示

```
显示AI消息气泡
显示时间戳
显示提供商标识（可选）
```

## 扩展性设计

```python

AI_PROVIDERS['new_provider'] = {
    'api_key': 'xxx',
    'base_url': 'https://...',
    'priority': 3,
    ...
}

# 2. 实现调用函数
def call_new_provider_api(messages, temperature, max_tokens):
    # 实现API调用
    pass

# 3. 在call_ai_with_fallback中添加调用
if provider == 'new_provider':
    result = call_new_provider_api(...)
```

### 添加新的预设场景

```python
# 后端：在AI_PROMPTS中添加
AI_PROMPTS['new_scenario'] = '新的提示词...'

# 前端：在_handleAICardTap中添加映射
case '新场景':
    chatType = 'new_scenario';
    systemPrompt = '新的提示词...';
```

---

**架构特点**：
- 🎯 **模块化**：前后端分离，职责清晰
- 🔄 **高可用**：自动降级，多重保障
- 🚀 **易扩展**：添加新提供商或场景只需少量代码
- 🛡️ **健壮性**：多层错误处理和重试机制
- 📱 **易用性**：前端调用简单，一行代码搞定
