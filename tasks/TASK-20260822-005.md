## 用户任务

站在中文环境下的外贸、外企和职场用户角色，解决“会单词但不会组织真实工作表达”的问题，形成可以商业化验证的“工作英语临场训练”首发版本，并直接落到当前唯一生产基座 `xuebadictApp`。

## 产品假设

用户不是缺少更多单词，而是在客户、同事或会议前缺少一条可执行路径：中文工作意图 → 自然英文表达 → 开口 → 只纠正一处 → 必须重说 → 迁移到新的工作场景。首发聚焦外贸/客户沟通，外企项目协作作为相邻角色，不同时扩展到所有英语学习者。

## 范围

- 包含：用户角色选择、工作场景选择、工作表达训练提示、三场景状态机、重说门槛、当前会话训练摘要的本地保存、产品规格与商业化验证方案。
- 复用：现有中文到英文页面、AI Chat、录音转写、EchoType 工作英语例句资产和现有 `shared_preferences` 依赖。
- 不包含：新支付接口、真实会员权益校验、服务端训练记录 API、发音评分模型、重新复制完整 GitHub App。
- 商业边界：免费/Pro 只写清首发销售假设和产品入口，不把本地计数或已有支付页面写成已完成的生产收费能力。
